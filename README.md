# rene-mk2-navigator

travelers guide for charting cartesian space: a one-page reference for the **make noise rené mk2** cartesian sequencer. the three channels, every program page, a map of what each touch pad does on each page, all sixteen snake patterns, the fun options, quantizer, latch, the 64 states, mesh and multi-paste, the global page, jacks, the select bus and calibration.

source: the make noise rené manual (firmware v133).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with make noise.
